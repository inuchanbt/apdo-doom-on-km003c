# APDO DOOM installer for Windows x64

対象は KM003C **HW 2.3／純正FW 2.0.7** です。ファームの書き換えには文鎮化や純正データを失うリスクがあります。純正時点から同じ個体・同じPC側USBポートを使い、測定側の両ポートを空にして、側面HIDだけを接続してください。MTOOLSなどの機器を使うソフトは閉じます。

旧版を導入済みの場合は、その版のインストーラーと元のバックアップで純正に復元してから始めます。

ZIPを展開し、`Install-APDO-DOOM.cmd` をダブルクリックします。Windows標準のPowerShellと同梱の実行ファイルで動作します。バックアップ先を空欄にすると `%LOCALAPPDATA%\APDO DOOM\Backups` に専用フォルダーを作ります。復元にはそのフォルダー全体が必要です。個体情報と校正情報を含むため非公開で保管してください。

1. **Back up and install DOOM** は純正データを取得し、手動DFUで同じ個体を照合します。`INSTALL` を入力するとファームを書き込み、全バイトを照合して起動します。その後、外部NORの4 MiBを2回読み取り、照合が通ったら `DOOM.DAT` を書き込みます。全4 MiBの読み戻しを照合してからゲームを起動します。
2. **Back up stock firmware only** は書き込みを行わず、純正ファームと外部NORの先頭3 MiBを含むバックアップを作ります。あとで項目1にこのフォルダーを指定できます。外部NORの残り1 MiBは項目1でゲームデータを書き込む前に取得します。
3. **Restore original NOR and stock firmware** は項目1で保存したフォルダーを選びます。指示に従って手動DFUに入り、次の起動でOKを押し続けてFreedoomのロゴが出たら離します。外部NORを復元し全4 MiBを照合したあと、自動でDFUに戻って純正ファームを書き込み、純正の起動を照合します。終了後は純正画面と測定機能を確認してください。
4. **Recover stock app after an app-only install failure** は、項目1がゲームデータの書き込みを開始する前に止まった場合に使います。当時のインストーラーフォルダーを指定し、画面の指示で手動DFUに入ります。
5. **Remove leftover DOOM data after stock firmware was already restored** は、既に純正アプリへ戻したもののゲームデータが残っている場合に使います。`Remove-Leftover-DOOM-Data.cmd` からも開始できます。元の検証済みバックアップを指定し、一時的に保存領域サービスを書き込んでNORを復元したあと、純正アプリへ戻します。[詳しい手順](REMOVE-DOOM-DATA.md)を読んでください。この追加操作の実機検証は未実施です。

手動DFUは、本体のExitを押しながら側面HIDを挿し直し、純正の更新画面で離します。外部NORの書き込みが中断され、読み戻しが純正・ゲーム版のどちらの既知状態とも一致しない場合、復元は停止します。画面のエラーとフォルダーを保管してください。

同梱のファームとゲームデータは [v0.1.2-independent](https://github.com/inuchanbt/apdo-doom-on-km003c/releases/tag/v0.1.2-independent) の公開バイナリに対応します。新しいHID通信には同梱の対応PCツールを使ってください。対応ソースと依存ライセンスは同リリースの `-source.tar.gz` と、同梱の `-notices.zip` を参照してください。ゲームデータは Freedoom E1M1 です。

2026-11-11に所有者が新ファームの書き込みと正常動作を確認しました。この版で初回導入から完全復元までを再検証したという報告ではありません。従来のHW2.1試験版はv0.1.1のリリースを利用してください。
