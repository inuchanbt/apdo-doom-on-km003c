# APDO DOOM HW 2.1 実機試験版（Windows x64）

読み取り調査でローダーと純正アプリのSHA-256が一致した **KM003C HW 2.1／純正FW 2.0.7** の試験版です。修正前の試験版では協力者の1台でゲーム動作を確認しました。この配布版の実機検証はこれからです。ファームやゲームデータの書き換えには文鎮化や純正データを失うリスクがあります。測定側の両ポートを空にして、側面HIDだけを接続してください。MTOOLSなどの機器を使うソフトを閉じ、同じ個体と同じPC側USBポートを使い続けます。

旧版を導入済みの場合は、その版のインストーラーと元のバックアップで純正に復元してから始めます。

ZIPを展開し、`Install-APDO-DOOM.cmd` をダブルクリックします。バックアップ先を空欄にすると `%LOCALAPPDATA%\APDO DOOM\Backups` に専用フォルダーを作ります。画面に表示された場所を控え、復元までフォルダー全体を保管してください。純正ファイルと校正情報は個体ごとのデータです。

1. **Back up and install DOOM** を選び、純正画面を表示した状態で開始します。純正アプリなどを読み取ったあと、側面HIDを抜き、Back/Exitを押しながら同じUSBポートへつなぎ直します。純正の更新画面でボタンを離し、PCでEnterを押すと、DFU側でも読み取って照合します。項目2で作ったバックアップを指定して導入することもできます。
2. `INSTALL` を入力すると、同梱の公開DOOMファームだけを書き込みます。Freedoomロゴが出たらPCでEnterを押し、`APDO replied from the splash` が表示されたら **HIDをつないだまま、Exitを2秒以上長押し**します。インストーラーが同じUSBポートのDFUとアプリの読み戻しを確認します。この段階で止まった場合は、メニューの項目4で純正へ戻せます。
3. Exit試験が通るとDOOMファームを再起動し、外部NOR全4 MiBを2回読んで純正バックアップと照合します。`GAME` を入力すると `DOOM.DAT` を書き込みます。全4 MiBを照合してからゲームを起動し、フレームが進んだことを確認します。ゲーム画面とボタン操作を確認できたら `YES` を入力してください。
4. **純正に戻すには**、もう一度起動して項目3 **Restore original NOR and stock firmware** を選び、同じフォルダーを指定します。`RESTORE` と入力して手動DFUに入ったあと、本体のOKを押しながらPCのEnterを押し、ロゴが出てからOKを離します。外部NORを先に戻して照合し、次に純正ファームを戻します。純正画面とUSBテスター機能が戻ったことを確認できたら `YES` を入力してください。

項目4 **Recover stock app after an app-only install failure** は、ゲームデータの書き込みを開始する前に中断した場合の入口です。当時のフォルダーを指定し、`APP-ONLY` と入力して、画面の指示で手動DFUに入ります。ゲーム書き込みを開始したあとの復元は項目3を使います。外部NORが書き込み途中の状態で純正とゲーム版のどちらにも一致しない場合は、復元が停止します。エラー表示とバックアップ一式を保管してください。

試験後は、フォルダー内の **`hw21-doom-*.json` だけ**を返してください。導入、復元、中断の各操作について、通過した段階を記録します。途中で止まった場合は、シリアルや個人のパスを伏せて画面のエラーも添えてください。

同梱のファームとFreedoom E1M1データは [v0.1.1-independent](https://github.com/inuchanbt/apdo-doom-on-km003c/releases/tag/v0.1.1-independent) に対応します。対応ソースとライセンスは同リリースの `-source.tar.gz` と同梱の `-notices.zip` を参照してください。
